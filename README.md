# Finerz (free-to-play)

Finerz — Telegram бот-игры в стиле "казино", **без реальных денег** (только виртуальные монеты).

## Быстрый старт (локально/хост)

```bash
npm i
npm run build
BOT_TOKEN="твой_токен" ADMIN_IDS="твой_id" npm start
```

## Переменные окружения
- `BOT_TOKEN` — токен @BotFather (**обязательно**)
- `ADMIN_IDS` — id админов через запятую (например `123,456`)
- `HOUSE_EDGE` — house edge для Mines (по умолчанию 0.03 = 3%)
- `- `BET_MIN` — минимальная ставка (по умолчанию 0.1)
- `- `BET_MAX` — максимальная ставка (по умолчанию 500)

## Команды
- `/start` — старт
- `/help` — помощь
- `/profile` — профиль
- `/balance` — баланс
- `/daily` — ежедневка
- `/ref` — реф-ссылка
- `/games` — игры/коэффициенты
- `/mystats` — статистика по играм
- `/history 10` — история (последние N)
- `/top` — топ по монетам
- `/myid` — показать свой Telegram ID

### Игры
- `/dice <ставка>`
- `/slot <ставка>`
- `/mines <ставка> <мины 1-23>` + кнопки выбора клеток + `/pick <1-25>` + `/cashout`
- `/tower <ставка>` + кнопки A/B + `/step A|B` + `/tower_cashout`

## Хранение
SQLite файл `kaz.db` создаётся рядом с запуском и хранит баланс, историю и статистику.


### Виртуальные пополнение/вывод
- `/deposit <сумма>` — заявка на виртуальное пополнение
- `/withdraw <сумма>` — заявка на виртуальный вывод
- (админы) `/pending`, `/deposit_ok <id>`, `/deposit_no <id>`, `/withdraw_ok <id>`, `/withdraw_no <id>`
